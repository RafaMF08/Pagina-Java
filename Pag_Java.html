Java

Escríbelo una vez y ejecútalo donde quieras

Java es un lenguaje de programación creado en 1991 que hoy mueve servidores, bancos, videojuegos y millones de aplicaciones. Aquí tienes su historia, cómo es su código y cómo empezar.

Con Java se hacen

De un proyecto secreto a un estándar mundial

1991

James Gosling y su equipo de Sun Microsystems empiezan el proyecto Green. El lenguaje se llamaba Oak.

1995

Oak pasa a llamarse Java y se presenta al público, pensado para funcionar en internet.

1996

Llega el JDK 1.0, el primer kit oficial para programar en Java.

2006

Sun libera Java como software libre y nace OpenJDK.

2010

Oracle compra Sun Microsystems y pasa a dirigir Java.

2014

Java 8 incorpora lambdas y streams, y el código se vuelve más corto y expresivo.

2017

Java pasa a sacar una versión nueva cada seis meses.

2023

Java 21 (LTS) trae hilos virtuales para manejar miles de tareas a la vez.

2025

Java 25, la última versión LTS, mantiene el ritmo de dos lanzamientos al año.

Las personas y la empresa detrás de Java

James Gosling

Informático canadiense que lideró el diseño de Java en Sun Microsystems. Con Mike Sheridan y Patrick Naughton formó el equipo inicial del proyecto Green, en 1991.

Sun Microsystems

Empresa estadounidense de ordenadores y software que creó y lanzó Java. En 2010 la compró Oracle, que hoy dirige la plataforma junto a la comunidad de OpenJDK.

De Oak a Java

El lenguaje nació como Oak, nombre que según se cuenta venía de un roble junto a la oficina de Gosling. Un conflicto de marca obligó a cambiarlo y el equipo eligió Java.

El lema original

Sun resumía la idea en “escribe una vez, ejecuta en cualquier sitio”: compilas tu programa una sola vez y funciona en cualquier sistema que tenga una JVM.

Por qué Java sigue en todas partes

Portable

El código se compila a bytecode y la JVM lo ejecuta igual en cualquier sistema operativo.

Orientado a objetos

Todo se organiza en clases y objetos, lo que facilita mantener proyectos grandes.

Tipado estático

El compilador detecta muchos errores antes de ejecutar el programa.

Memoria automática

El recolector de basura libera la memoria que ya no se usa, sin que lo hagas a mano.

Multihilo

Permite hacer varias tareas a la vez, desde hilos clásicos hasta hilos virtuales.

Ecosistema enorme

Miles de librerías y frameworks maduros, y una comunidad que lleva décadas creciendo.

Compilar y empaquetar un proyecto con paquetes

      
Cuando hay varias clases y paquetes, cada paquete es una carpeta. Pulsa el botón para ver la secuencia.

      
Terminal

      

      

      
La estructura de carpetas
El paquete com.ejemplo corresponde a la carpeta src/com/ejemplo. Los .class conservan esa estructura dentro de out.
Estructura
mi-app/
├── src/com/ejemplo/Main.java
├── src/com/ejemplo/Util.java
└── out/com/ejemplo/Main.class

      
Nombre completo de la clase
Para ejecutar usas el nombre con su paquete: com.ejemplo.Main, y -cp out dice dónde buscar.
Crear el .jar
En jar cfe, c crea, f nombra el archivo y e indica la clase principal. -C out . incluye todo el contenido de out.
Usar librerías
Con -cp añades otros .jar a la ruta, por ejemplo libs/*, separados con dos puntos o con punto y coma.
Muchos archivos a la vez
En Linux y macOS puedes escribir src/com/ejemplo/*.java. En Windows, usa un archivo de lista con @.
Si algo falla
Comprueba que estás en la carpeta correcta y que el nombre del paquete coincide con las carpetas.
Maven y Gradle
En proyectos grandes lo normal es dejar que Maven o Gradle hagan todo esto por ti.

    


    

      
Pasar datos al programa desde la terminal

      
Lo que escribes después del nombre de la clase llega al método main en el array args. Prueba a cambiar los argumentos.

      
El programa
args guarda cada argumento como un texto. args.length indica cuántos hay.
Saludo.java
public class Saludo {
    public static void main(String[] args) {
        System.out.println("Recibí " + args.length + " argumentos");
        for (int i = 0; i < args.length; i++) {
            System.out.println(i + ": " + args[i]);
        }
    }
}


      
Pruébalo
Escribe los argumentos tal como los pondrías en la terminal. Con comillas, varias palabras forman un solo argumento.

        
java Saludo

      
Terminal

      
Todo son textos
Si quieres un número, conviértelo: Integer.parseInt(args[1]).
Sin argumentos
Si no pasas nada, args.length vale 0. Acceder a args[0] provoca un ArrayIndexOutOfBoundsException.
Con un .jar
Funciona igual: java -jar app.jar Ana 20.

Programación orientada a objetos

      
Java organiza los programas en objetos, que juntan datos y acciones. Estos son sus cuatro pilares.

      
Encapsulación
Los datos son privados y solo se tocan mediante métodos controlados.
Herencia
Una clase puede heredar los datos y métodos de otra y añadir los suyos.
Polimorfismo
Un mismo método se comporta distinto según el objeto que lo ejecuta.

      
Clase y objeto
La clase es el molde y el objeto es cada ejemplar creado con new.
Coche.java
class Coche {
    String marca;
    int velocidad;

    void acelerar() {
        velocidad += 10;
    }
}

Coche miCoche = new Coche();
miCoche.marca = "Seat";
miCoche.acelerar();

      
Encapsulación
El saldo es privado: solo se cambia con ingresar, que comprueba la cantidad.
Cuenta.java
class Cuenta {
    private double saldo;

    public double getSaldo() {
        return saldo;
    }

    public void ingresar(double cantidad) {
        if (cantidad > 0) {
            saldo += cantidad;
        }
    }
}

      
Herencia
Gato hereda comer de Animal y añade su propio método.
Gato.java
class Animal {
    void comer() {
        System.out.println("Comiendo");
    }
}

class Gato extends Animal {
    void maullar() {
        System.out.println("Miau");
    }
}

      
Polimorfismo
Una variable de tipo Figura puede guardar un círculo y calcular su área.
Figuras.java
class Figura {
    double area() { return 0; }
}

class Circulo extends Figura {
    double radio = 2;

    @Override
    double area() { return Math.PI * radio * radio; }
}

Figura f = new Circulo();
System.out.println(f.area());

Errores que todo el mundo comete

      
Olvidar el punto y coma
Cada instrucción termina en punto y coma, y cada llave abierta se cierra.
Dividir enteros
5 / 2 vale 2, porque ambos son int. Usa 5.0 / 2 para obtener 2.5.
Mayúsculas importan
Main y main son nombres distintos, y el nombre de la clase debe coincidir con el archivo.
NullPointerException
Aparece al usar un objeto que vale null, es decir, que no se ha creado todavía.
Índice fuera de rango
Los arrays empiezan en 0: uno de tres elementos llega solo hasta el índice 2.
Variable sin inicializar
Java no deja usar una variable local antes de darle un valor.

Más instrucciones útiles

      
switch moderno
El switch con flechas devuelve un valor y no necesita break.
Switch.java
int dia = 3;
String nombre = switch (dia) {
    case 1 -> "lunes";
    case 2 -> "martes";
    case 3 -> "miércoles";
    default -> "otro día";
};

      
do-while, break y continue
do-while ejecuta antes de comprobar. continue salta una vuelta y break sale del bucle. Imprime 1, 3 y 4.
Bucle.java
int n = 0;
do {
    n++;
    if (n == 2) continue;
    if (n > 4) break;
    System.out.println(n);
} while (true);

      
Operador ternario
Es un if else en una sola línea que devuelve un valor.

Generas un par de claves, subes la pública a GitHub y no tienes que escribir nada más al hacer push.

    Ejercicios para practicar
    
      
    Intenta resolver cada uno por tu cuenta y pulsa para ver una solución posible.
    
      
    1. Par o imparEscribe un programa que diga si un número es par o impar.
    Solucion.java
    int n = 7;
if (n % 2 == 0) {
    System.out.println("par");
} else {
    System.out.println("impar");
}
    
      
    2. FactorialCalcula el factorial de 5, es decir, 5 · 4 · 3 · 2 · 1.
    Solucion.java
    int n = 5;
long f = 1;
for (int i = 2; i <= n; i++) {
    f *= i;
}
System.out.println(f); // 120
    
      
    3. FizzBuzzDel 1 al 15 imprime Fizz si es múltiplo de 3, Buzz si lo es de 5 y FizzBuzz si lo es de ambos.
    Solucion.java
    for (int i = 1; i <= 15; i++) {
    if (i % 15 == 0) System.out.println("FizzBuzz");
    else if (i % 3 == 0) System.out.println("Fizz");
    else if (i % 5 == 0) System.out.println("Buzz");
    else System.out.println(i);
}
    
      
    4. Contar vocalesCuenta cuántas vocales tiene la palabra “programacion”.
    Solucion.java
    String texto = "programacion";
int vocales = 0;
for (char c : texto.toCharArray()) {
    if ("aeiou".indexOf(c) >= 0) {
        vocales++;
    }
}
System.out.println(vocales); // 5
    
      
    5. PalíndromoComprueba si una palabra se lee igual al revés.
    Solucion.java
    String s = "reconocer";
String alReves = new StringBuilder(s).reverse().toString();
System.out.println(s.equals(alReves)); // true
    
      
    6. Media de notasCalcula la media de las notas 7, 9, 5 y 8.
    Solucion.java
    int[] notas = {7, 9, 5, 8};
int suma = 0;
for (int n : notas) {
    suma += n;
}
double media = (double) suma / notas.length;
System.out.println(media); // 7.25

    Cómo aprender Java, paso a paso
    
      
    
        
    Sintaxis
    Variables, tipos, condicionales y bucles.
    
        
    Métodos
    Dividir el código en piezas reutilizables.
    
        
    Objetos
    Clases, herencia e interfaces.
    
        
    Colecciones
    Listas, mapas y conjuntos.
    
        
    Errores
    Excepciones y depuración.
    
        
    Archivos y datos
    Leer, escribir y usar bases de datos.
    
        
    Un framework
    Por ejemplo Spring Boot.
    
        
    Un proyecto propio
    Lo que más enseña: construir algo tuyo.
    
      
    
      
    Glosario rápido
    
      
    
        
    JDK
    Kit de desarrollo con el compilador y las herramientas para programar.
    
        
    JVM
    La máquina virtual que ejecuta el bytecode.
    
        
    Bytecode
    Código intermedio que genera el compilador.
    
        
    JIT
    Compilador que acelera las partes más usadas mientras el programa corre.
    
        
    Recolector de basura
    Libera la memoria de los objetos que ya no se usan.
    
        
    Paquete
    Carpeta lógica que agrupa clases relacionadas.

    Tu primer programa en cuatro pasos
    
      
    
        
    
          
    Instala un JDK, por ejemplo OpenJDK o Temurin.
    
          
    Crea un archivo Main.java con el ejemplo de “Hola mundo”.
    
          
    Compila con javac Main.java.
    
          
    Ejecuta con java Main.
